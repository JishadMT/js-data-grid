# Sample Node.js JsDataGrid App

A sample Node.js + Express app serving `GET` and `POST` paginated endpoints and a UI with two `JsDataGrid` instances (API-backed and client-side data).

## Build / Setup

Install dependencies:

```bash
npm install

```

*(If serving `js-data-grid` from `node_modules` or placing local vendor/CSS files in `public/` or an external directory, ensure those assets are in place before starting.)*

## Start

Run the server:

```bash
npm start

```

Open `http://localhost:3000` in your browser.
